Hard Context Ablation
============================================================

The classifier is trained once using true context + comment.
At test time only, the context is replaced with increasingly difficult wrong contexts.

Split sizes: train=16000, test=4000
Same-subreddit match coverage: 0.8470
Mean semantic-hard-negative cosine similarity: 0.4451

Interpretation:
- Replacing the true context with a random context reduces Macro-F1 by about 0.0165. The paired 95% bootstrap CI is fully above zero.
- Replacing it with a wrong context from the same subreddit also reduces Macro-F1 by about 0.0150. The paired 95% bootstrap CI is fully above zero.
- A semantically similar but incorrect context produces essentially the same Macro-F1 as the true context, and the paired CI includes zero.

This suggests that the embedding-based classifier benefits from topic/semantic compatibility in the context, but does not reliably distinguish the exact conversational context from a semantically similar incorrect one.
